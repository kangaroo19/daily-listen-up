관리자 페이지의 1차 목적은?

daily-listen-up MVP 이후 바로 필요한 운영 기능을 기준으로 골라주세요. 여러 개가 필요하면 화면에서 여러 항목을 클릭해도 됩니다.

A

콘텐츠 운영 중심

문제 풀 등록, 오디오 파일 확인, 날짜별 퀴즈 배정, 공개 여부 관리.

B

보상/유저 상태 중심

사용자 진행 상태, 정답/오답, rewardStatus, 포인트 지급 실패/재처리 대상 확인.

C

QA/운영 점검 중심

오늘 문제 조회, 광고 이후 채점 흐름, 스크립트 열람, Storage 오디오 URL 검증.

내 추천

초기 관리자 페이지는 A 콘텐츠 운영 + C QA 점검이 가장 값이 큽니다. 지금 문서상 운영 병목이 문제 적재와 날짜 배정이고, 보상 재처리는 권한/감사 로그 설계가 필요해서 2단계로 빼는 편이 안전합니다.
