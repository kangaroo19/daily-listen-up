# 문제 풀이 화면

## 목적

사용자가 오늘의 영어 음성을 듣고, 5개 선택지 중 하나를 골라 객관식 문제에 답할 수 있게 한다.

## 진입 조건

- 사용자가 홈에서 시작하기를 눌렀다.
- 로그인과 사용자 식별이 완료되었다.
- 오늘 제공할 문제가 있다.
- 사용자가 아직 오늘 학습을 완료하지 않았다.

## 사용자에게 보여줄 내용

- 오늘의 영어 음성
- 음성 청취 후 풀 수 있는 객관식 문제
- 5개 선택지
- 선택한 답안을 제출할 수 있는 주요 액션

## 주요 액션

- 오디오 재생
  - 사용자가 오늘의 영어 음성을 들을 수 있게 한다.
- 선택지 선택
  - 사용자가 5개 선택지 중 하나를 고른다.
- 답안 제출
  - 선택한 답안을 제출하고 결과 확인 흐름으로 이동한다.

## 다음 흐름

- 답안 제출 후 광고 시청을 거쳐 결과 화면으로 이동한다.
- 사용자가 답안을 선택하지 않은 경우 제출할 수 없게 한다.
- 이미 오늘 학습이 완료된 상태로 확인되면 결과 화면의 완료 상태로 이동한다.

## 상세 스펙에서 나중에 정할 것

- 오디오 자동 재생 여부
- 오디오 재생 중 선택지를 숨길지 보여줄지
- 답안 제출 전 광고 진입 방식
- 문제 로딩 실패 시 안내 방식
- 선택지와 제출 버튼의 정확한 문구와 UI 상태
