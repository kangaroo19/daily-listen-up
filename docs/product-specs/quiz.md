# 문제 풀이 화면

## 목적

사용자가 오늘의 영어 음성과 5개 선택지를 확인하고, 정답이라고 생각하는 항목 1개를 골라 객관식 문제에 답할 수 있게 한다.

## 진입 조건

- 사용자가 홈에서 시작하기를 눌렀다.
- 로그인과 사용자 식별이 완료되었다.
- 오늘 제공할 문제가 있다.
- 오늘 문제의 `progressStatus`가 `not_started`, `wrong`, `retry_unlocked` 중 하나다.
- 문제 풀이 화면 진입 시 `GET /api/today-quiz`로 오늘 문제 콘텐츠를 불러온다.
- 문제 풀이 화면은 `GET /api/today-quiz` 응답의 `quizDate`를 보관하고, 이후 답안 제출과 광고 보상 요청에 같은 `quizDate`를 사용한다.

## 사용자에게 보여줄 내용

- 오늘의 영어 음성
- 단일 선택 객관식 문제
- 5개 선택지
- 선택지 목록 이후, `답안 제출` 주요 액션 이전에 노출되는 Toss Ads 배너 광고
- 선택한 답안을 제출할 수 있는 주요 액션

## 문구 초안

- 제목: `정답을 골라주세요`
- 안내: `음성은 한 번만 들을 수 있어요. 듣는 중에도 답을 고를 수 있어요.`
- 재생 버튼: `듣기 시작`
- 제출 버튼: `답안 제출`
- 제출 실패 토스트: `답안을 보내지 못했어요. 다시 시도해 주세요.`
- 로딩 실패 안내: `문제를 불러오지 못했어요.`
- 재시도 버튼: `다시 시도`

## 오디오 재생 정책

- 오디오는 자동 재생하지 않는다.
- 사용자가 직접 재생 버튼을 눌러 시작한다.
- 오디오는 각 시도마다 1회만 들을 수 있다.
- 오디오 재생 완료 여부와 관계없이 선택지는 바로 보여준다.
- 오디오 재생 완료 여부와 관계없이 선택 답안이 1개이면 제출할 수 있다.

## 단일 선택 정책

- 문제 콘텐츠 조회 후 5개 선택지를 바로 보여준다.
- 사용자는 5개 선택지 중 정답이라고 생각하는 항목 1개만 선택할 수 있다.
- 다른 선택지를 누르면 기존 선택은 해제되고 새 선택지만 선택 상태가 된다.
- 정확히 1개를 선택해야 제출할 수 있다.
- 답안 제출 API의 기존 선택 답안 목록 필드명은 유지하되, 클라이언트는 선택지 ID 1개만 담아 제출한다.

## 정답 판정 기준

- 사용자가 선택한 항목 1개가 서버에 저장된 정답 선택지 목록과 정확히 일치해야 정답이다.
- 정답 선택지 목록에는 운영상 정답 ID 1개만 둔다.
- 복수 선택과 부분 정답은 MVP에서 다루지 않는다.

## 주요 액션

- 오디오 재생
  - 사용자가 오늘의 영어 음성을 들을 수 있게 한다.
- 선택지 선택
  - 사용자가 5개 선택지 중 정답이라고 생각하는 항목 1개를 고른다.
- 답안 제출
  - 답안 제출 버튼 안에 `답안 제출` 텍스트와 광고/영상 성격의 아이콘을 함께 표시한다.
  - 선택한 답안을 제출하고 광고 시청을 거쳐 결과 화면으로 이동한다.
  - 답안 제출 후 결과 확인 전면형 광고의 `dismissed` 이벤트가 발생하면 `POST /api/answer-result`로 선택 답안을 제출한다.
  - `POST /api/answer-result`에는 선택 답안과 `GET /api/today-quiz`에서 받은 `quizDate`를 함께 전달한다.
  - 첫 제출은 서버의 `progressStatus = not_started` 상태에서 허용된다.
  - 재제출은 서버의 `progressStatus = retry_unlocked` 상태에서만 허용되며, 제출 처리 시 재도전권은 소진된다.
  - `progressStatus = wrong` 상태에서 다시 제출하려면 먼저 결과 화면의 보상형 광고를 완료해 `retry_unlocked` 상태를 확보해야 한다.
  - `POST /api/answer-result` 응답을 받으면 정답/오답 판정 결과를 가지고 결과 화면으로 이동한다.

## 문제 또는 오디오 로딩 실패

- 문제 풀이 화면 안에서 짧은 오류 안내를 보여준다.
- 사용자가 같은 화면에서 다시 시도할 수 있게 한다.
- 홈이나 결과 화면으로 자동 이동하지 않는다.
- 로딩 상태와 오류/재시도 상태에는 배너 광고를 노출하지 않는다.

## 배너 광고 노출 정책

- 문제 풀이 정상 상태에서는 선택지 목록 이후, 하단 `답안 제출` 버튼 이전에 Toss Ads 배너 광고를 노출한다.
- 배너는 선택지와 제출 CTA를 가리지 않도록 96px 높이 슬롯에 배치한다.
- Toss Ads 배너 API 미지원, 초기화 실패, 광고 없음, 렌더링 실패 상태에서는 사용자 토스트 없이 배너 슬롯을 비운다.
- 답안 제출 후 전면형 광고가 진행되는 동안에는 별도 배너 광고를 추가하지 않는다.

## 다음 흐름

- 답안 제출 후 광고 시청을 거쳐 결과 화면으로 이동한다.
- 사용자가 답안을 1개 선택하지 않은 경우 제출할 수 없게 한다.
- 오답 후 광고 보상으로 재도전하면 같은 문제 풀이 화면으로 돌아오며, 새 시도에서 오디오를 다시 1회 들을 수 있다.
- 이미 오늘 학습이 완료된 상태로 확인되면 문제 풀이 화면으로 이동하지 않고 홈에서 완료 토스트를 보여준다.
