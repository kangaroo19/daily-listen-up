# 15. 오늘의 문제 없음 상태 구현

## 목적

KST 기준 오늘 날짜에 해당하는 문제 데이터가 없을 때 사용자가 오류, 오답, 완료 상태로 오해하지 않게 `오늘의 문제 준비 중` 상태를 보여준다.

이 작업은 Firebase 문제 조회 결과의 `empty` 상태를 전용 화면으로 표현하는 작업이며, 대체 문제나 운영 기능을 만들지 않는다.

## 구현 범위

- 4번 작업에서 정의한 오늘 문제 조회 결과의 `empty` 상태를 처리한다.
- 로그인 완료 후 오늘 문제가 없는 경우 전용 안내 화면을 보여준다.
- 오늘 문제 없음 상태와 조회 실패, 잘못된 문제 데이터, 오늘 학습 완료 상태를 구분한다.
- 문제 풀이, 답안 제출, 광고, 보상 흐름으로 이동하지 않게 한다.
- 사용자가 다시 조회할 수 있는 재시도 CTA를 제공한다.
- 홈 또는 시작 화면으로 돌아가는 최소 액션을 제공한다.
- 모바일 WebView safe area를 고려해 하단 CTA를 배치한다.

## 제외 범위

- Firebase 문제 데이터 생성, 수정, 업로드 기능
- 관리자 화면
- AI 문제 자동 생성
- 다른 날짜 문제 제공, 랜덤 문제, 복습 문제
- 내일 문제 미리보기 상세 화면
- 오디오 재생, 객관식 퀴즈, 제출, 광고, 보상 흐름
- 운영자 알림, 모니터링, 배치 작업
- completed 문서 작성

## 구현 기준

- 오늘 문제 없음 상태는 `quizQuery.empty` 또는 같은 의미의 상태만 기준으로 한다.
- `empty` 상태에는 `quiz` 객체를 전달하지 않는다.
- `empty`와 `invalid`, `error`를 같은 화면으로 합치지 않는다.
- `empty`는 사용자가 잘못한 상태가 아니라 콘텐츠가 아직 준비되지 않은 상태로 표현한다.
- 화면 상단에는 오늘 문제 준비 상태를 짧게 표시한다.
- 화면 중앙에는 오늘 문제가 아직 없다는 안내를 짧고 직접적으로 둔다.
- 화면 하단에는 재시도 또는 홈으로 돌아가기 CTA를 둔다.
- 주요 CTA는 TDS `Button`을 우선 사용하고 `display="full"` 기준으로 배치한다.
- 재시도 CTA는 Firebase 오늘 문제 조회를 다시 실행하는 동작으로 제한한다.
- 재시도 중에는 CTA에 `loading`과 `disabled`를 함께 적용한다.
- 오늘 문제 없음 상태에서는 문제 풀이 페이지로 이동하는 CTA를 제공하지 않는다.
- 오늘 문제 없음 상태에서는 답안 제출 API, 광고 API, 포인트 지급 API를 호출하지 않는다.
- 이미 오늘 학습 완료 상태인 사용자는 문제 데이터가 없어도 완료 화면을 우선한다.
- 문구는 완료, 오답, 보상 실패와 혼동되지 않게 작성한다.
- 운영 준비 상태를 길게 설명하지 않고 사용자가 지금 할 수 있는 행동만 안내한다.

## 상태 및 예외 처리

- `empty_today_quiz`: 오늘 날짜 문제 데이터가 없다.
- `retrying`: 오늘 문제 데이터를 다시 조회 중이다.
- `ready_after_retry`: 재시도 후 오늘 문제 데이터가 확인되었다.
- `still_empty`: 재시도 후에도 오늘 문제 데이터가 없다.
- `invalid_quiz`: 문제 문서는 있지만 필수 필드가 잘못되었다.
- `query_error`: Firebase 조회 실패, 권한 오류, 네트워크 오류가 발생했다.
- `completed_priority`: 진행 상태가 완료라서 문제 없음보다 완료 화면을 우선해야 한다.
- 재시도 중에는 중복 조회가 발생하지 않게 한다.
- 재시도 후 문제가 있으면 5번 오늘의 문제 진입 흐름으로 돌아간다.
- 재시도 후에도 문제가 없으면 같은 empty 화면을 유지한다.
- 조회 실패는 `오늘의 문제 준비 중`이 아니라 오류 상태로 구분한다.
- 잘못된 문제 데이터는 사용자에게 상세 필드 오류를 노출하지 않고 시작할 수 없는 상태로 처리한다.
- KST 자정이 지나면 새 `quizDate` 기준으로 다시 조회한다.

## 완료 기준

- 오늘 날짜 문제 데이터가 없으면 `오늘의 문제 준비 중` 상태가 표시된다.
- 오늘 문제 없음 상태에서는 문제 풀이, 제출, 광고, 보상 흐름이 시작되지 않는다.
- 오늘 문제 없음 상태와 조회 실패 상태가 구분된다.
- 오늘 문제 없음 상태와 오늘 학습 완료 상태가 구분된다.
- 완료 사용자는 문제 없음보다 완료 화면을 우선해 본다.
- 재시도 CTA가 중복 조회를 만들지 않는다.
- 재시도 후 문제가 확인되면 오늘 문제 진입 흐름으로 돌아갈 수 있다.
- 대체 문제, 관리자 기능, AI 생성, 내일 문제 미리보기 같은 MVP 밖 기능이 포함되지 않는다.
- TDS 우선, 모바일 WebView safe area, 짧고 직접적인 문구 기준을 따른다.
