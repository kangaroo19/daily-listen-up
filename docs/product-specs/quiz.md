# 문제 풀이 화면

## 목적

사용자가 오늘의 영어 음성을 듣고, 5개 선택지 중 정답이라고 생각하는 항목을 여러 개 골라 객관식 문제에 답할 수 있게 한다.

## 진입 조건

- 사용자가 홈에서 시작하기를 눌렀다.
- 로그인과 사용자 식별이 완료되었다.
- 오늘 제공할 문제가 있다.
- 사용자가 아직 오늘 학습을 완료하지 않았다.
- 문제 풀이 화면 진입 시 `GET /api/today-quiz`로 오늘 문제 콘텐츠를 불러온다.

## 사용자에게 보여줄 내용

- 오늘의 영어 음성
- 음성 청취 후 풀 수 있는 복수응답 객관식 문제
- 5개 선택지
- 선택한 답안을 제출할 수 있는 주요 액션

## 문구 초안

- 청취 전 제목: `오늘의 영어를 들어보세요`
- 청취 전 안내: `음성을 끝까지 들은 뒤 문제를 풀 수 있어요.`
- 재생 버튼: `듣기 시작`
- 청취 완료 후 제목: `정답이라고 생각하는 답을 모두 골라주세요`
- 제출 버튼: `답안 제출`
- 로딩 실패 안내: `문제를 불러오지 못했어요.`
- 재시도 버튼: `다시 시도`

## 오디오 재생 정책

- 오디오는 자동 재생하지 않는다.
- 사용자가 직접 재생 버튼을 눌러 시작한다.
- 오디오는 각 시도마다 1회만 들을 수 있다.
- 오디오 청취가 끝나기 전에는 선택지를 보여주지 않는다.

## 복수응답 선택 정책

- 오디오 청취 완료 후 5개 선택지를 보여준다.
- 사용자는 5개 선택지 중 정답이라고 생각하는 항목을 여러 개 선택할 수 있다.
- 선택 개수에는 별도 제한을 두지 않는다.
- 최소 1개 이상 선택해야 제출할 수 있다.

## 정답 판정 기준

- 사용자가 선택한 항목이 정답 선택지 목록과 정확히 일치해야 정답이다.
- 모든 정답을 선택하고, 오답 선택지는 하나도 선택하지 않아야 한다.
- 부분 정답은 MVP에서 별도 성공 상태로 다루지 않는다.

## 주요 액션

- 오디오 재생
  - 사용자가 오늘의 영어 음성을 들을 수 있게 한다.
- 선택지 선택
  - 사용자가 5개 선택지 중 정답이라고 생각하는 항목을 모두 고른다.
- 답안 제출
  - 답안 제출 버튼 안에 `답안 제출` 텍스트와 광고/영상 성격의 아이콘을 함께 표시한다.
  - 선택한 답안을 제출하고 광고 시청을 거쳐 결과 화면으로 이동한다.
  - 답안 제출 후 결과 확인 전면형 광고의 `dismissed` 이벤트가 발생하면 `POST /api/answer-result`로 선택 답안을 제출한다.
  - 서버 판정 결과에 따라 결과 화면으로 이동한다.

## 문제 또는 오디오 로딩 실패

- 문제 풀이 화면 안에서 짧은 오류 안내를 보여준다.
- 사용자가 같은 화면에서 다시 시도할 수 있게 한다.
- 홈이나 결과 화면으로 자동 이동하지 않는다.

## 다음 흐름

- 답안 제출 후 광고 시청을 거쳐 결과 화면으로 이동한다.
- 오디오 청취를 완료하지 않은 경우 제출할 수 없게 한다.
- 사용자가 답안을 1개 이상 선택하지 않은 경우 제출할 수 없게 한다.
- 오답 후 광고 보상으로 재도전하면 같은 문제 풀이 화면으로 돌아오며, 새 시도에서 오디오를 다시 1회 들을 수 있다.
- 이미 오늘 학습이 완료된 상태로 확인되면 결과 화면의 완료 상태로 이동한다.
