Goal: quiz-content-seeding 기준과 아래 A/B 검수 프롬프트를 사용해서 functions/src/content/quizPool.json에 운영 가능한 영어 듣기 퀴즈 문제 N개를 추가하고 JSON 검증까지 완료한다.

작업 조건:
- 기존 quizPool.json의 id와 소재를 확인하고 중복을 피한다.
- 날짜 정보는 절대 넣지 않는다.
- mp3 파일은 아직 만들지 않고 audioFileName만 지정한다.
- audioFileName은 "{id}.mp3" 형식으로 작성한다.
- promotionAmount는 5로 고정한다.
- 최종적으로 quizPool.json이 유효한 JSON인지 검증한다.

서브에이전트 실행 조건:
- 이 작업은 반드시 실제 Codex subagent 2개를 생성해서 진행한다.
- 단순히 "서브에이전트 A/B" 역할을 혼자 시뮬레이션하지 않는다.
- 먼저 서브에이전트 A와 서브에이전트 B를 각각 독립된 agent로 spawn한다.
- 서브에이전트 A는 문제 출제와 B의 지적 반영을 담당한다.
- 서브에이전트 B는 A가 만든 초안을 아래 검수 기준으로 독립 검수한다.
- 메인 에이전트는 두 서브에이전트의 결과를 모두 기다린 뒤, B의 지적 사항을 반영해 quizPool.json에 최종 JSON 객체를 추가한다.
- 서브에이전트는 quizPool.json을 직접 수정하지 않는다. 파일 수정과 JSON 검증은 메인 에이전트가 수행한다.

너는 daily-listen-up의 퀴즈 콘텐츠 제작 파이프라인이다.

목표:
- 영어 듣기 퀴즈를 만든다.
- 결과물은 functions/src/content/quizPool.json 배열에 바로 추가할 수 있는 JSON 객체여야 한다.
- 날짜 정보는 절대 넣지 않는다.

제품 맥락:
- 사용자는 초급~중급 영어 학습자다.
- 하루에 짧은 영어 오디오 1개를 듣고, 5개 선택지 중 정답이라고 생각하는 항목을 모두 고른다.
- 학습은 토스 앱 안에서 가볍게 끝나야 하므로 소재는 실생활 중심이어야 한다.

공통 제작 기준:
- script는 영어로 작성한다.
- script는 음성 기준 45초~1분 분량이어야 한다.
- 난이도는 A2~B1 생활영어 수준으로 맞춘다.
- 문장은 너무 길지 않게 쓴다.
- 선택지 text는 한국어로 작성한다.
- choices는 정확히 5개다.
- correctChoiceIds는 1~2개만 포함한다.
- 정답 선택지는 script에서 명확히 확인 가능해야 한다.
- 오답 선택지는 그럴듯할 수는 있지만 script와 명확히 충돌해야 한다.
- id는 kebab-case로 작성한다.
- audioFileName은 "{id}.mp3" 형식으로 작성한다.
- promotionAmount는 5로 작성한다.

서브에이전트 A - 문제 출제자:
1. 일상적인 영어 듣기 상황을 하나 정한다.
2. 45초~1분 분량의 영어 script를 작성한다.
3. script의 핵심 사실을 바탕으로 한국어 선택지 5개를 만든다.
4. 정답은 1~2개만 고른다.
5. 아래 JSON 형식의 초안을 만든다.

서브에이전트 B - 문제 검수자:
A의 초안을 다음 기준으로 검수한다.
1. JSON 필드가 id, audioFileName, script, choices, correctChoiceIds, promotionAmount만 있는가?
2. id와 audioFileName 규칙이 맞는가?
3. script가 A2~B1 수준이고 45초~1분 분량에 적절한가?
4. choices가 정확히 5개인가?
5. correctChoiceIds가 choices에 존재하는 id만 참조하는가?
6. 정답이 1~2개인가?
7. 모든 정답은 script에서 직접 근거를 찾을 수 있는가?
8. 모든 오답은 script와 명확히 충돌하는가?
9. 선택지끼리 중복되거나 너무 비슷하지 않은가?
10. 사용자가 듣기만으로 풀 수 없는 외부지식 문제가 없는가?
11. 기존 quizPool.json의 문제와 id 또는 소재가 중복되지 않는가?

서브에이전트 A - 최종 수정:
- B가 지적한 문제가 있으면 모두 수정한다.
- 최종 출력에는 검수 리포트, 설명, markdown, 주석을 넣지 않는다.
- 오직 JSON 객체만 출력한다.
- 여러 문제를 만들 때는 JSON 객체들을 quizPool.json 배열에 추가한다.

최종 JSON 객체 형식:
{
  "id": "example-id",
  "audioFileName": "example-id.mp3",
  "script": "...",
  "choices": [
    { "id": "choice-a", "text": "..." },
    { "id": "choice-b", "text": "..." },
    { "id": "choice-c", "text": "..." },
    { "id": "choice-d", "text": "..." },
    { "id": "choice-e", "text": "..." }
  ],
  "correctChoiceIds": ["choice-a"],
  "promotionAmount": 5
}

완료 기준:
- functions/src/content/quizPool.json에 문제 N개가 추가되어 있다.
- 기존 문제와 id가 중복되지 않는다.
- choices는 각 문제마다 정확히 5개다.
- correctChoiceIds는 각 문제마다 1~2개다.
- correctChoiceIds는 실제 choices의 id만 포함한다.
- script는 영어이고 선택지는 한국어다.
- JSON 파싱 검증이 통과한다.
