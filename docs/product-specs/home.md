# 홈

## 목적

사용자가 `daily-listen-up`이 어떤 미니앱인지 빠르게 이해하고, 오늘의 영어 듣기 문제를 시작할 수 있게 한다.

## 진입 조건

- 사용자가 미니앱에 진입한다.
- 사용자가 아직 오늘의 문제 풀이 화면으로 이동하지 않았다.

## 사용자에게 보여줄 내용

- 미니앱에 대한 간략한 설명
- 하루에 짧은 영어 듣기 문제 1개를 푸는 서비스라는 점
- 정답 시 토스 포인트 보상 대상이 될 수 있다는 점
- 오늘의 문제를 시작할 수 있는 하단 주요 액션

## 문구 초안

- 제목: `오늘의 영어 듣고 포인트 받기`
- 설명: `짧은 영어 음성을 듣고 문제를 맞히면 토스 포인트 보상에 도전할 수 있어요.`
- 보조 설명: `하루에 한 문제만 제공돼요.`
- 주요 버튼: `시작하기`

## 주요 액션

- `시작하기`
  - 사용자가 누르면 토스 로그인 흐름으로 진입한다.
  - 로그인 이후 오늘의 문제 풀이 화면으로 이동한다.
  - 기본 상태에서는 활성화한다.
  - 로그인 진행 중이거나 오늘 문제가 없는 상태에서는 비활성화한다.

## 로그인 실패 또는 취소

- 사용자는 홈에 머문다.
- 짧은 안내를 보여주고 다시 `시작하기`를 누를 수 있게 한다.
- 안내 문구 초안: `로그인을 완료하지 못했어요. 다시 시작해 주세요.`

## 오늘 문제 없음 상태

- 별도 주요 화면으로 만들지 않고 홈 안 상태로 표현한다.
- `시작하기` 버튼 대신 준비 중 상태를 보여준다.
- 문구 초안: `오늘의 문제가 아직 준비되지 않았어요.`
- 보조 문구 초안: `잠시 후 다시 확인해 주세요.`

## 다음 흐름

- 로그인과 사용자 식별이 완료되면 문제 풀이 화면으로 이동한다.
- 이미 오늘 학습을 완료한 사용자라면 결과 화면의 완료 상태로 이동한다.
- 오늘 제공할 문제가 없다면 준비 중 상태로 이동한다.
