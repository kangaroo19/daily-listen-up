# 결과 화면

## 목적

사용자가 제출한 답안의 정답 여부를 확인하고, 결과에 따라 포인트 보상 또는 재도전 흐름을 이어갈 수 있게 한다.

## 진입 조건

- 사용자가 문제 풀이 화면에서 답안을 제출했다.
- 사용자가 결과 확인을 위한 전면형 광고를 열고 `dismissed` 이벤트 이후 답안 제출 API 응답을 받았다.

## 사용자에게 보여줄 내용

- `POST /api/answer-result` 응답에 따른 정답 또는 오답 상태
- 정답인 경우 오늘 학습 완료 안내와 포인트 지급 상태
- 오답인 경우 광고 보상 기반 재도전 액션
- 정답과 오답 상태에서 광고 보상 후 열람할 수 있는 듣기 스크립트 액션
- 결과/스크립트 콘텐츠 이후, 액션 버튼 묶음 이전에 노출되는 Toss Ads 배너 광고
- 광고 실패 또는 취소 시 같은 결과 화면에서 다시 시도할 수 있는 안내

## 문구 초안

- 정답 제목: `정답이에요`
- 정답 안내: `포인트 보상 상태를 확인해 주세요.`
- 오답 제목: `아쉬워요`
- 오답 안내: `광고를 보고 같은 문제에 다시 도전할 수 있어요.`
- 완료 제목: `오늘 학습을 완료했어요`
- 완료 안내: `내일 새로운 문제로 다시 만나요.`
- 포인트 대기: `포인트 지급을 확인하고 있어요.`
- 포인트 완료: `포인트 지급이 완료됐어요.`
- 포인트 실패: `포인트 지급을 완료하지 못했어요. 잠시 후 다시 확인하거나 고객센터에 문의해 주세요.`
- 재도전 버튼: `광고 보고 재도전`
- 스크립트 버튼: `광고 보고 스크립트 보기`
- 광고 실패 안내: `광고를 완료하지 못했어요. 다시 시도해 주세요.`

## 결과 상태

- 정답
  - `POST /api/answer-result` 응답의 정답 여부가 정답인 상태다.
  - 정답 판정 즉시 `progressStatus = completed`가 된다.
- 오답
  - `POST /api/answer-result` 응답의 정답 여부가 오답인 상태다.
  - 오답 판정 즉시 `progressStatus = wrong`이 된다.
- 오늘 완료
  - 오늘 문제에 대한 학습이 완료되어 추가 풀이와 중복 보상 흐름으로 진입할 수 없는 상태다.
  - 정답 직후에 적용된다.
  - MVP에서는 완료 사용자가 홈에서 다시 `시작하기`를 눌러도 결과 화면으로 재진입하지 않고 홈 토스트만 본다.

## 포인트 지급 상태

- 오늘 완료 상태에서는 `rewardStatus`를 `pending`, `success`, `failed`로 구분해 `대기`, `완료`, `실패` 안내를 보여준다.
- 상세 실패 사유나 서버 에러 코드는 MVP 결과 화면에 노출하지 않는다.
- 지급 실패 상태에서도 오늘 학습 완료 상태는 유지한다.
- 지급 실패 상태에서는 정답 직후 결과 화면 안에서 짧은 안내를 보여준다.
- 완료 사용자가 홈에서 다시 진입한 경우 지급 실패 상세 화면으로 이동하지 않고 홈 토스트로 `포인트 지급 확인이 필요해요`를 보여준다.

## 오답 재도전 정책

- 오답 상태에서는 `광고 보고 재도전` 버튼을 제공한다.
- 사용자가 리워드형 광고를 완료하면 서버가 `progressStatus = retry_unlocked`로 기록하고 같은 문제의 문제 풀이 화면으로 돌아간다.
- 재도전권은 광고 1회 완료마다 1회만 제공하며 누적하지 않는다.
- 다음 답안 제출 시 서버가 재도전권을 검증하고 제출 처리와 함께 소진한다.
- 재도전 횟수는 화면에 표시하지 않는다.
- 리워드형 광고를 취소하거나 실패하면 결과 화면에 머물고 다시 시도할 수 있게 한다.

## 스크립트 보기 정책

- 정답과 오답 상태 모두에서 `광고 보고 스크립트 보기` 버튼을 제공한다.
- 사용자가 리워드형 광고를 완료하면 `POST /api/rewarded-ad-complete` 응답으로 받은 `script`를 같은 결과 화면 안에 펼쳐 보여준다.
- 오답 사용자가 스크립트를 본 뒤에도 재도전할 수 있으며, 이는 **의도된 학습 흐름**이다.
- 스크립트 보기 광고를 취소하거나 실패하면 결과 화면에 머물고 다시 시도할 수 있게 한다.
- 스크립트는 광고 완료 전에는 보여주지 않는다.

## 주요 액션

- 보상 확인
  - 정답인 사용자가 포인트 보상 흐름을 확인한다.
- 광고 보고 재도전
  - 오답인 사용자가 광고 보상을 완료한 뒤 같은 문제에 다시 도전한다.
- 광고 보고 스크립트 보기
  - 사용자가 광고 보상을 완료한 뒤 서버 응답의 `script`를 같은 결과 화면에서 확인한다.

## 배너 광고 노출 정책

- 결과 정상 상태에서는 결과 패널과 스크립트 패널 이후, 하단 액션 버튼 묶음 이전에 Toss Ads 배너 광고를 노출한다.
- 결과 정보, 스크립트, 재도전/스크립트/홈 액션을 가리지 않도록 96px 높이 슬롯에 배치한다.
- 결과 정보가 없는 완료 대체 화면에는 배너 광고를 노출하지 않는다.
- Toss Ads 배너 API 미지원, 초기화 실패, 광고 없음, 렌더링 실패 상태에서는 사용자 토스트 없이 배너 슬롯을 비운다.
- 재도전 또는 스크립트 보기 보상형 광고가 진행되는 동안에는 별도 배너 광고를 추가하지 않는다.

## 상세 스펙에서 나중에 정할 것

- TDS 컴포넌트 선택
- 재도전 버튼과 스크립트 버튼에 사용할 정확한 아이콘
