# 홈

## 목적

사용자가 `daily-listen-up`이 어떤 미니앱인지 빠르게 이해하고, 오늘의 영어 듣기 문제를 시작할 수 있게 한다.

## 진입 조건

- 사용자가 미니앱에 진입한다.
- 사용자가 아직 오늘의 문제 풀이 화면으로 이동하지 않았다.

## 사용자에게 보여줄 내용

- 미니앱에 대한 간략한 설명
- 하루에 짧은 영어 듣기 문제 1개를 푸는 서비스라는 점
- 정답 시 토스 포인트 보상 대상이 될 수 있다는 점
- 오늘의 문제를 시작할 수 있는 하단 주요 액션

## 주요 액션

- `시작하기`
  - 사용자가 누르면 토스 로그인 흐름으로 진입한다.
  - 로그인 이후 오늘의 문제 풀이 화면으로 이동한다.

## 다음 흐름

- 로그인과 사용자 식별이 완료되면 문제 풀이 화면으로 이동한다.
- 이미 오늘 학습을 완료한 사용자라면 결과 화면의 완료 상태로 이동한다.
- 오늘 제공할 문제가 없다면 준비 중 상태로 이동한다.

## 상세 스펙에서 나중에 정할 것

- 홈 화면의 정확한 문구
- 시작하기 버튼의 비활성화 조건
- 로그인 실패 또는 취소 시 사용자 안내
- 오늘 문제 없음 상태를 홈에서 보여줄지 별도 상태로 보여줄지
