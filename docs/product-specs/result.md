# 결과 화면

## 목적

사용자가 제출한 답안의 정답 여부를 확인하고, 결과에 따라 포인트 보상 또는 재도전 흐름을 이어갈 수 있게 한다.

## 진입 조건

- 사용자가 문제 풀이 화면에서 답안을 제출했다.
- 사용자가 결과 확인을 위한 광고 시청 흐름을 거쳤다.
- 이미 오늘 학습을 완료한 사용자가 앱에 다시 진입했다.

## 사용자에게 보여줄 내용

- 사용자의 정답 여부
- 정답인 경우 포인트 보상 흐름
- 오답인 경우 재도전 가능 여부
- 오늘 학습 완료 상태

## 문구 초안

- 정답 제목: `정답이에요`
- 정답 안내: `포인트 보상 상태를 확인해 주세요.`
- 오답 제목: `아쉬워요`
- 오답 안내: `광고를 보고 같은 문제에 다시 도전할 수 있어요.`
- 완료 제목: `오늘 학습을 완료했어요`
- 완료 안내: `내일 새로운 문제로 다시 만나요.`
- 포인트 대기: `포인트 지급을 확인하고 있어요.`
- 포인트 완료: `포인트 지급이 완료됐어요.`
- 포인트 실패: `포인트 지급을 완료하지 못했어요. 잠시 후 다시 확인하거나 고객센터에 문의해 주세요.`
- 재도전 버튼: `광고 보고 재도전`
- 스크립트 버튼: `광고 보고 스크립트 보기`
- 광고 실패 안내: `광고를 완료하지 못했어요. 다시 시도해 주세요.`

## 결과 상태

- 정답
  - 사용자가 제출한 복수응답이 정답 선택지 목록과 정확히 일치한 상태다.
  - 정답 판정 즉시 오늘 학습 완료 상태가 된다.
- 오답
  - 사용자가 제출한 복수응답이 정답 선택지 목록과 정확히 일치하지 않은 상태다.
- 오늘 완료
  - 오늘 문제에 대한 학습이 완료되어 추가 풀이와 중복 보상 흐름으로 진입할 수 없는 상태다.
  - 정답 직후와 이미 오늘 학습을 완료한 사용자의 재진입에 모두 적용된다.

## 포인트 지급 상태

- 오늘 완료 상태에서는 포인트 지급 상태를 `대기`, `완료`, `실패`로 구분해 보여준다.
- 상세 실패 사유나 서버 에러 코드는 MVP 결과 화면에 노출하지 않는다.
- 지급 실패 상태에서도 오늘 학습 완료 상태는 유지한다.
- 지급 실패 상태에서는 사용자가 상황을 이해할 수 있는 짧은 안내와 고객 문의 또는 잠시 후 재확인 안내를 보여준다.

## 오답 재도전 정책

- 오답 상태에서는 `광고 보고 재도전` 버튼을 제공한다.
- 사용자가 리워드형 광고를 완료하면 같은 문제의 문제 풀이 화면으로 돌아간다.
- 재도전 횟수는 화면에 표시하지 않는다.
- 리워드형 광고를 취소하거나 실패하면 결과 화면에 머물고 다시 시도할 수 있게 한다.

## 스크립트 보기 정책

- 정답과 오답 상태 모두에서 `광고 보고 스크립트 보기` 버튼을 제공한다.
- 사용자가 리워드형 광고를 완료하면 같은 결과 화면 안에 스크립트를 펼쳐 보여준다.
- 오답 사용자가 스크립트를 본 뒤에도 재도전할 수 있으며, 이는 의도된 학습 흐름이다.
- 스크립트 보기 광고를 취소하거나 실패하면 결과 화면에 머물고 다시 시도할 수 있게 한다.
- 스크립트는 광고 완료 전에는 보여주지 않는다.

## 주요 액션

- 보상 확인
  - 정답인 사용자가 포인트 보상 흐름을 확인한다.
- 광고 보고 재도전
  - 오답인 사용자가 광고 보상을 완료한 뒤 같은 문제에 다시 도전한다.
- 완료 상태 확인
  - 이미 오늘 학습을 완료한 사용자가 당일 완료 상태를 확인한다.

## 다음 흐름

- 정답이면 오늘 학습 완료 상태로 이어진다.
- 정답 후 포인트 지급 상태가 실패여도 오늘 학습 완료 상태는 유지한다.
- 오답이고 광고 보상을 완료하면 문제 풀이 화면으로 돌아가 같은 문제에 재도전한다.
- 오답이고 광고 보상을 완료하지 않으면 재도전 기회를 주지 않는다.
- 이미 오늘 학습을 완료한 사용자는 추가 풀이 또는 중복 보상 흐름으로 진입하지 않는다.

## 상세 스펙에서 나중에 정할 것

- TDS 컴포넌트 선택
- 재도전 버튼과 스크립트 버튼에 사용할 정확한 아이콘
