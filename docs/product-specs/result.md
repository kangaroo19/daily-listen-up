# 결과 화면

## 목적

사용자가 제출한 답안의 정답 여부를 확인하고, 결과에 따라 포인트 보상 또는 재도전 흐름을 이어갈 수 있게 한다.

## 진입 조건

- 사용자가 문제 풀이 화면에서 답안을 제출했다.
- 사용자가 결과 확인을 위한 광고 시청 흐름을 거쳤다.
- 이미 오늘 학습을 완료한 사용자가 앱에 다시 진입했다.

## 사용자에게 보여줄 내용

- 사용자의 정답 여부
- 정답인 경우 포인트 보상 흐름
- 오답인 경우 재도전 가능 여부
- 오늘 학습 완료 상태

## 주요 액션

- 보상 확인
  - 정답인 사용자가 포인트 보상 흐름을 확인한다.
- 광고 보고 재도전
  - 오답인 사용자가 광고 보상을 완료한 뒤 같은 문제에 다시 도전한다.
- 완료 상태 확인
  - 이미 오늘 학습을 완료한 사용자가 당일 완료 상태를 확인한다.

## 다음 흐름

- 정답이면 오늘 학습 완료 상태로 이어진다.
- 오답이고 광고 보상을 완료하면 문제 풀이 화면으로 돌아가 같은 문제에 재도전한다.
- 오답이고 광고 보상을 완료하지 않으면 재도전 기회를 주지 않는다.
- 이미 오늘 학습을 완료한 사용자는 추가 풀이 또는 중복 보상 흐름으로 진입하지 않는다.

## 상세 스펙에서 나중에 정할 것

- 정답, 오답, 완료 상태의 정확한 문구
- 포인트 지급 대기, 성공, 실패 상태 표현
- 광고 보상 실패 또는 취소 시 안내 방식
- 재도전 횟수 표시 여부
- 정답 해설 또는 스크립트 공개 여부
